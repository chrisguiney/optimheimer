# Optimheimer

Optimheimer is a personal project mostly intended to eat developer time.


The goal is to make a path tracing environment

- vulkan and nuklear to supply an immediate mode UI
- NVIDIA Optix to supply a path tracing pipeline
- Julia? Guile Scheme? as an embedded scripting language

I don't quite know where the project is going.  I'll probably abandon it.

If things go well I'll stream some development of it.
